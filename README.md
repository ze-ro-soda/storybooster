# 🎭 스토리부스터 (StoryBooster)

스토리부스터는 SillyTavern 롤플레이의 **장르감**, **캐릭터성**, **플롯 전개**를 보조하는 확장 프로그램입니다.

- **장르 부스터**: 선택한 장르의 분위기와 표현을 꾸준히 강화합니다.
- **캐릭터 부스터**: 캐릭터의 성격·말투·행동·관계 반응을 기준으로 일관성을 보강합니다.
- **플롯 부스터**: 현재 대화에 어울리는 사건이나 다음 전개를 필요할 때 생성합니다.

세 기능은 각각 켜고 끌 수 있으며, 설정과 결과는 기능에 따라 채팅별 또는 캐릭터별로 저장됩니다.

## 설치

### GitHub 주소로 설치

1. SillyTavern의 **확장 관리** 화면을 엽니다.
2. 확장 설치 메뉴에 아래 주소를 입력합니다.

   `https://github.com/ze-ro-soda/storybooster`

3. 설치가 끝나면 SillyTavern을 새로고침합니다.
4. 채팅 입력창의 마법봉 메뉴에서 **스토리부스터**를 엽니다.

### 직접 설치

배포 폴더를 다음 위치에 `storybooster`라는 이름으로 복사한 뒤 SillyTavern을 새로고침합니다.

`SillyTavern/data/default-user/extensions/storybooster`

폴더 바로 안에 `manifest.json`, `index.js`, `style.css`가 있어야 합니다.

## 빠른 사용법

1. 롤플 채팅을 열고 마법봉 메뉴에서 **스토리부스터**를 실행합니다.
2. **장르 부스터**에서 주 장르를 선택합니다. 필요하면 보조 장르도 선택합니다.
3. **캐릭터 부스터**를 사용하려면 캐릭터 기준을 한 번 생성하고 내용을 확인합니다.
4. 사건이나 다음 전개가 필요할 때만 **플롯 부스터**를 사용합니다.
5. 추가 AI 호출을 원하지 않으면 확장 설정에서 **자동 진단 끄기**를 선택합니다.

파란색 `부스팅 중` 표시가 나타나면 해당 부스터의 지침이 캐릭터 응답에 적용되고 있는 상태입니다.

## 장르 부스터

주 장르는 장면의 중심 의미와 전개 방향을, 보조 장르는 분위기·관계 압력·세계의 질감을 보강합니다. 보조 장르는 주 장르를 밀어내지 않으며 현재 장면에 자연스러운 여지가 있을 때만 드러납니다.

장르 설정은 기존 프리셋이나 작가 노트의 내용을 삭제하거나 덮어쓰지 않고 별도 지침으로 적용됩니다. 현재 롤플 흐름에 맞춰 자유롭게 바꿔 사용할 수 있습니다.

주요 기능:

- 주 장르와 보조 장르 선택
- 현재 롤플에 어울리는 장르 추천
- 사용자 장르 직접 추가
- 수동 또는 자동 장르 진단
- 약화된 항목을 다음 캐릭터 응답 한 번에 보정
- 적용 대기 중인 보정 취소

기본 장르에는 로맨스, 롬콤, 일상, 드라마, 미스터리, 액션, 범죄, 판타지, SF, 공포, 코미디, 앵스트, 데드 도브, 섹텐, 욕망, NSFW 등이 포함됩니다. 화면에는 한국어 이름이 표시되고, 실제 모델에는 영어 지침이 전달됩니다.

## 캐릭터 부스터

캐릭터 카드에서 기준을 생성하면 다음 7개 항목으로 정리됩니다.

- 핵심 정체성
- 성격·특성
- 가치관·경계
- 목표·동기
- 행동·의사결정
- 대사·감정 표현
- 관계 반응

AI 기준 생성에는 캐릭터 카드의 **설명, 성격, 대화 예시**만 사용합니다. 이름, 시나리오, 첫 메시지는 요약 자료에 포함하지 않습니다.

각 항목은 직접 수정하거나 개별 재생성할 수 있으며, 핀으로 고정하면 전체 재생성에서도 유지됩니다. 기준을 수정한 뒤에는 캐릭터 전용 앵커를 갱신해야 변경 내용이 부스팅에 반영됩니다.

캐릭터 부스팅에는 7개 기준 전체가 매번 들어가지 않습니다. AI가 만든 짧은 캐릭터 전용 앵커와 공통 보강 규칙만 사용하여 입력 토큰을 줄입니다. 캐릭터 카드를 편집해도 기존 기준과 앵커는 계속 유지되며, 설정을 크게 바꾼 경우에만 사용자가 전체 요약을 다시 실행하면 됩니다.

진단은 캐릭터 일관성, 캐릭터 해석, 능동성, 관계 반응, 연속성, 표현 다양성을 확인합니다. 보정이 필요하면 관련 기준을 최대 2개까지만 다음 캐릭터 응답 한 번에 사용합니다.

## 플롯 부스터

현재 대화와 선택한 카테고리를 바탕으로 **완성된 롤플 답변이 아닌 다음 전개용 플롯**을 생성합니다.

### 자유 생성

정보·발견, 비밀·단서, 제3자 개입, 목표·선택, 갈등·장애, 관계 변화, 감정 표출, 상황 변화, 결과·후폭풍, 일상·계기, 세계·세력, 돌발 변수 중 하나를 선택합니다. 사용자 카테고리도 직접 추가할 수 있습니다.

### 내 아이디어

키워드나 대략적인 내용을 입력하면 현재 롤플에 어울리는 플롯으로 다듬습니다.

생성된 결과에서는 다음 기능을 사용할 수 있습니다.

- **다듬기**: 핵심 방향을 유지하며 구체성과 개연성을 높입니다.
- **새 방향**: 최근 추천과 겹치지 않는 다른 전개를 만듭니다.
- **입력창에 넣기**: 결과를 채팅 입력창으로 옮깁니다.
- **주입 후 AI 응답 생성**: 플롯을 한 번 주입하고 현재 채팅 연결로 캐릭터 응답을 생성합니다.
- **결과 지우기**: 현재 결과만 삭제합니다.

최근 추천은 채팅별로 최대 5개까지 저장됩니다. 플롯 생성은 장르 부스터의 선택값을 직접 전달받지 않고 현재 대화와 카테고리에 집중합니다. 최신 캐릭터 전용 앵커가 있으면 캐릭터 붕괴를 줄이기 위한 참고 자료로만 사용합니다.

## 전역 설정

SillyTavern의 확장 관리 화면에서 설정할 수 있습니다.

- **기능 사용 여부**: 장르·캐릭터·플롯 부스터를 각각 완전히 끄거나 켭니다.
- **장르/캐릭터 진단 프로필**: 장르 추천·진단과 캐릭터 기준·앵커 생성에 사용할 연결입니다.
- **플롯 프로필**: 플롯 생성·다듬기·새 방향에 사용할 연결입니다.
- **자동 진단 주기**: 캐릭터 응답 5~15회 또는 자동 진단 끄기. 기본값은 10회입니다.
- **플롯 생성 토큰**: 기본값은 1200입니다.
- **출력 언어**: 한국어 또는 English를 선택합니다.

별도 프로필을 지정하지 않으면 현재 채팅의 기본 연결을 사용합니다. 지정한 프로필이 삭제되거나 사용할 수 없으면 다른 연결로 몰래 전환하지 않고 오류를 표시합니다.

플롯의 `주입 후 AI 응답 생성`에서 플롯 후보까지는 플롯 프로필을 사용하지만, 실제 롤플 답변은 현재 채팅의 기본 연결로 생성합니다.

## AI 호출과 토큰

상시 장르·캐릭터 부스팅 자체는 별도 AI 호출을 만들지 않습니다. 다음 작업에서만 추가 호출이 발생합니다.

- 장르 추천 및 수동·자동 진단
- 캐릭터 기준과 전용 앵커 생성
- 플롯 생성·다듬기·새 방향

장르 추천과 플롯 생성은 최근 대화 10개를 참고합니다. 진단은 최근 캐릭터 응답 최대 10개와 최신 펠소 메시지 1개를 사용합니다. 자동 진단을 끄면 부스팅과 수동 진단은 그대로 사용할 수 있습니다.

## 호환성과 주의사항

- OpenAI 호환 형식, Gemini 응답 구조, 일부 Thinking 모델의 reasoning 출력을 처리하도록 구성되어 있습니다.
- 실제 출력 품질과 JSON 준수 정도는 모델과 연결 제공자에 따라 달라질 수 있습니다.
- NSFW를 포함한 출력 범위는 사용 중인 모델과 제공자의 정책을 따릅니다.
- 백그라운드 요청이 3분 안에 끝나지 않으면 시간 초과로 중단됩니다.
- 그룹 채팅에서는 캐릭터 기준 기능을 사용할 수 없습니다.

## 문제 해결

### 확장이 보이지 않아요

- 확장 관리 화면에서 활성화 상태를 확인합니다.
- 설치 폴더 바로 안에 `manifest.json`, `index.js`, `style.css`가 있는지 확인합니다.
- SillyTavern을 새로고침합니다.

### `MAX_TOKENS` 또는 JSON 오류가 발생해요

- 플롯 생성 토큰을 높여 다시 시도합니다.
- Thinking 사용량이 적은 모델이나 다른 연결 프로필로 시험합니다.
- 연결 제공자의 최대 출력 토큰 설정을 확인합니다.

### 설정한 언어와 다르게 나와요

- 확장 설정의 출력 언어를 확인한 뒤 결과를 다시 생성합니다.
- 같은 문제가 반복되면 다른 모델이나 연결 프로필로 확인합니다.

### 자동 진단 호출을 사용하고 싶지 않아요

확장 설정의 자동 진단 주기에서 `자동 진단 끄기 · 추가 호출 없음`을 선택합니다.
