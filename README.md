# 📖 스토리부스터 (StoryBooster)

스토리부스터는 SillyTavern 롤플레이의 **장르감·캐릭터성·플롯 전개**를 보조하는 확장 프로그램입니다.

- **장르 부스터**: 선택한 장르의 분위기와 표현을 꾸준히 강화합니다.
- **캐릭터 부스터**: 캐릭터의 성격·말투·행동·관계 반응을 보강합니다.
- **플롯 부스터**: 현재 대화에 맞는 사건이나 다음 전개를 필요할 때 생성합니다.

각 기능은 전역 설정에서 따로 켜거나 끌 수 있습니다.

## 설치

1. SillyTavern의 **확장 관리**에서 확장 설치 메뉴를 엽니다.
2. 아래 주소를 입력합니다.

   `https://github.com/ze-ro-soda/storybooster`

3. 설치가 끝나면 SillyTavern을 새로고침합니다.
4. 채팅 입력창의 마법봉 메뉴에서 **스토리부스터**를 엽니다.

직접 설치할 때는 배포 파일을 다음 위치의 `storybooster` 폴더에 넣습니다.

`SillyTavern/data/default-user/extensions/storybooster`

폴더 바로 안에 `manifest.json`, `index.js`, `style.css`가 있어야 합니다.

## 빠른 사용법

1. **장르 부스터**에서 주 장르와 필요한 보조 장르를 선택합니다.
2. **캐릭터 부스터**는 캐릭터 기준을 생성·확인하고 전용 앵커를 준비합니다.
3. 다음 전개가 필요할 때 **플롯 부스터**에서 카테고리 또는 내 아이디어를 선택해 생성합니다.

파란색 `부스팅 중` 표시가 나타나면 해당 부스터 지침이 캐릭터 응답에 적용되고 있는 상태입니다.

## 기능 안내

### 장르 부스터

주 장르는 장면의 중심 의미와 전개 방향을, 보조 장르는 분위기·관계 압력·세계의 질감을 보강합니다. 기존 프리셋이나 작가 노트의 설정을 삭제하지 않고 별도 지침으로 적용됩니다.

- 주·보조 장르 선택 및 사용자 장르 추가
- 현재 롤플 장르 추천
- 수동·자동 장르 진단
- 약화된 항목의 다음 응답 1회 보강

### 캐릭터 부스터

캐릭터 카드의 설명·성격·대화 예시를 바탕으로 성격, 가치관, 동기, 행동, 말투, 관계 반응 등의 기준을 정리합니다. 항목별 수정·재생성·핀 고정이 가능하며, 최신 전용 앵커가 준비되면 부스팅을 시작합니다.

매 응답에는 기준 전체가 아니라 **짧은 캐릭터 전용 앵커와 공통 보강 규칙만 사용**해 입력 토큰을 줄입니다. 캐릭터 카드의 설명·성격·대화 예시가 바뀌면 재확인 안내를 표시하지만, 기존 기준과 앵커의 부스팅은 중단하지 않습니다. 이 알림은 전역 설정에서 끌 수 있습니다.

출력 언어가 한국어이면 기준과 앵커를 한국어로 표시하되 실제 부스팅에는 영문 앵커를 사용합니다. 한국어 앵커를 직접 수정해 저장할 때는 영문 주입본을 만들기 위해 분석 프로필을 한 번 사용합니다.

- 캐릭터 기준 생성·수정 및 전용 앵커 갱신
- 캐릭터 카드 변경 감지와 기존 기준 유지 선택
- 앵커 직접 편집·취소 및 마지막 저장 시간 표시
- 캐릭터성·해석·능동성·관계·연속성·표현 다양성 진단
- 약화된 항목의 다음 응답 1회 보강

### 플롯 부스터

현재 대화와 선택한 카테고리를 바탕으로 완성된 롤플 답변이 아닌 **다음 전개용 플롯**을 생성합니다.

- 카테고리 자유 생성 또는 내 아이디어 다듬기
- 현재 결과 다듬기와 다른 방향 생성
- 입력창에 넣기 또는 주입 후 AI 응답 생성
- 채팅별 최근 추천 최대 5개 보관
- 채팅별 **비밀모드**: 선택한 카테고리에 맞는 사건을 플롯 공개 없이 바로 전개
- **랜덤박스**: 카테고리와 결과를 숨긴 채 무작위 사건 전개
- **미친 랜덤박스**: 현재 흐름과 개연성을 벗어난 예측 불가능한 전개까지 허용
- **캐릭터의 질문**: 현재 장면을 유지한 채 주제 제한 없이 예측할 수 없는 질문을 마지막 장면으로 생성

플롯 후보는 장르 부스터 선택값을 직접 전달받지 않으며 현재 대화와 선택 카테고리를 우선합니다. 최신 캐릭터 전용 앵커가 있으면 캐릭터 일관성을 위한 참고 자료로 사용합니다.

비밀모드는 채팅마다 따로 켜며 기본값은 꺼짐입니다. 비밀모드로 생성한 플롯도 응답 후 최근 추천에서 확인할 수 있습니다. 랜덤박스와 미친 랜덤박스는 비밀모드에서만 표시됩니다. 캐릭터의 질문은 별도의 플롯 분석 호출 없이 현재 채팅 연결이 바로 작성합니다.

## 전역 설정

- 장르·캐릭터·플롯 부스터 사용 여부
- 장르/캐릭터 분석 연결 프로필
- 플롯 생성 연결 프로필
- 자동 진단 주기: 끄기 또는 캐릭터 응답 5~15회, 기본 10회
- 플롯 생성 토큰: 기본 1200
- 출력 언어: 한국어 또는 English
- 캐릭터 시트 변경 알림 사용 여부
- 현재 채팅방의 주입 프롬프트·글자 수·토큰 수 확인
- 최근 오류 진단 로그 3건 확인·복사·삭제

별도 프로필을 지정하지 않으면 현재 채팅의 기본 연결을 사용합니다. 지정한 프로필을 사용할 수 없을 때는 다른 연결로 자동 전환하지 않고 오류를 표시합니다. `주입 후 AI 응답 생성`의 실제 롤플 답변은 현재 채팅 연결로 생성합니다.

## AI 호출 및 주의사항

장르·캐릭터 부스팅 자체에는 **별도 AI 호출이 발생하지 않습니다.** 장르 추천·진단, 캐릭터 기준·앵커 생성, 플롯 생성 작업에서만 추가 호출이 발생합니다. 자동 호출을 원하지 않으면 전역 설정에서 자동 진단을 끌 수 있습니다.

- 모델과 연결 제공자에 따라 출력 품질과 JSON 준수 정도가 달라질 수 있습니다.
- 요청이 3분 안에 끝나지 않으면 시간 초과로 중단됩니다.
- `MAX_TOKENS`나 잘림 오류가 반복되면 플롯 생성 토큰 또는 연결 프로필의 출력 한도를 확인합니다.
- NSFW를 포함한 출력 범위는 사용 중인 모델과 제공자의 정책을 따릅니다.
- 그룹 채팅에서는 캐릭터 기준 기능을 사용할 수 없습니다.

세부 장르, 캐릭터 기준, 플롯 카테고리와 진단 결과 설명은 별도 사용 가이드를 참고해 주세요.
