# 스토리부스터 (StoryBooster)

SillyTavern에서 매 응답의 장르 연출 큐를 동적으로 바꾸고, 현재 대화 맥락에 맞는 사건을 AI로 자유롭게 만드는 확장.

## 설치

1. 이 폴더를 GitHub 저장소에 그대로 push (manifest.json이 루트에 있어야 함)
2. SillyTavern → Extensions → Install Extension → `https://github.com/sagwaringoapple/storybooster` 입력
3. 채팅창의 마법봉(지팡이) 메뉴에서 "스토리부스터" 확인

## 업데이트 흐름

1. 로컬에서 코드 수정
2. GitHub에 push
3. ST의 Extensions 관리 화면에서 해당 확장 "Update" 클릭 (또는 재설치)

## 파일 구조

- `manifest.json` — 확장 메타데이터 (필수)
- `index.js` — 메인 로직 (동적 장르 디렉터 + AI 사건 생성·검토·적용)
- `style.css` — UI 스타일
- `README.md` — 이 문서

## 장르 구성

- **주 장르**: 하나만 선택하며, 매 응답에서 이야기의 중심 장르로 유지됨.
- **보조 장르**: 최대 2개. 응답마다 교대하지 않고 둘 다 약하고 안정적인 질감으로 주 장르를 보조함.
- **기본 장르 분류**
  - 이야기 장르: Slice of Life, Romance, Drama, Mystery, Action, Adventure, Horror
  - 분위기·톤: Comedy, Dark, Healing, Suspense
  - 세계관: Fantasy, Sci-Fi, Historical, Supernatural
- **사용자 장르**: 팝업의 `원하는 장르 직접 추가`에서 이름과 선택적인 방향 설명을 입력할 수 있음. 추가한 장르는 확장 전체 목록에 저장되어 다른 채팅에서도 선택할 수 있지만, 실제 주·보조 선택은 채팅별로 저장됨.
- **중복 방지**: 같은 장르를 주 장르와 보조 장르에 동시에 지정하거나 두 보조 칸에 중복 지정하면 뒤쪽 중복 선택이 자동으로 해제됨.

### 코드에서 기본 장르 추가

```js
{ id: "새id", label: "표시 이름", emoji: "🔥", group: "story", enabled: false }
```

`GENRE_PROFILES`에 같은 id의 프로필을 추가하면 전용 기본 방향과 연출 큐를 사용할 수 있음. 프로필이 없는 장르는 장르 이름을 이용한 기본 큐가 자동 적용됨.

### 사건 카테고리 수정

```js
"새 카테고리"
```

`비`, `소문`, `질투`처럼 미리 정해진 카드는 사용하지 않음. 선택한 카테고리와 현재 채팅 맥락을 바탕으로 AI가 매번 새로운 사건 후보를 생성함.

## 동작 원리

- **적용 범위**: 주·보조 장르와 디렉터의 현재 단계·고정 상태는 `extension_settings[MODULE_NAME].chats[chatId]`에 저장됨 → **현재 열려 있는 채팅방에만** 적용됨. 사용자 추가 장르 목록만 확장 전체에서 공유됨.
- **0.3.0 설정 이전**: 예전 버전에서 여러 장르를 켜 두었다면 첫 번째 장르가 주 장르, 다음 두 장르가 보조 장르로 자동 이전됨.
- **진입 방법**: 채팅창의 마법봉(지팡이) 메뉴 → "🎭 스토리부스터" 클릭. 팝업 상단의 `장르 부스터`와 `플롯 부스터` 탭에서 기능을 분리해 사용함. 탭을 이동해도 팝업이 열려 있는 동안 선택값과 생성된 사건은 유지됨. 확장 관리 화면(Extensions 설정)에는 이 확장에 대한 개별 UI가 없음.
- **연속성 우선 장르 디렉터**: 주 장르와 구체적인 연출 큐가 영어 프롬프트로 `setExtensionPrompt()`의 depth 0 위치에 주입됨. 하나의 큐를 기본 3회 응답 동안 유지하며, 팝업에서 느긋하게(4회)·균형(3회)·빠르게(2회)를 선택할 수 있음. 추가 AI 호출은 사용하지 않음.
- **복수 장르**: 주 장르는 고정된 중심으로 유지됨. 보조 장르는 응답마다 교대하거나 개별 사건을 일으키지 않고, 선택한 장르 모두가 약하고 안정적인 배경 질감으로 유지됨.
- **장면 유지**: `장면 유지`를 켜면 큐 순환뿐 아니라 새로운 사건·갑작스러운 발견·장면 전환·시간 이동을 억제하고 현재 대화와 행동, 감정선만 깊게 이어감.
- **큐 조작**: `다음 연출 큐`를 누르면 유지 횟수를 기다리지 않고 즉시 다음 주 장르 큐로 이동함.
- **장르/플롯 역할 분리**: 장르 부스터는 현재 장면의 묘사·행동·대사 이면·감정 리듬을 강화하지만 큰 사건을 억지로 만들지 않음. 의도적인 사건과 급격한 전개는 플롯 부스터에서 사용자가 직접 생성함.
- **사건 후보 생성**: 카테고리를 고르고 "사건 후보 생성"을 누르면 `generateQuietPrompt()`가 현재 캐릭터·세계관·대화 맥락을 유지한 채 백그라운드에서 사건 하나를 생성함. 결과는 팝업 아래의 편집 가능한 칸에 표시됨.
- **디렉터와 사건의 연동**: 사건 후보는 현재 선택된 주 장르·보조 장르·연출 큐를 함께 참고하므로 장르 부스터의 다음 전개 방향과 어울리게 생성됨.
- **다시 생성**: 현재 후보가 마음에 들지 않으면 같은 카테고리에서 직전 후보와 다른 사건을 다시 생성함.
- **입력창에 넣기**: 생성 결과를 채팅 입력창으로 옮겨 사용자가 직접 수정하고 전송할 수 있음.
- **주입 후 AI 응답 생성**: 생성 결과를 다음 응답 직전(depth 0)에 숨은 시스템 지시로 1회 주입하고 `generate("normal")`을 호출해 사용자 입력 없이 즉시 AI 답변을 생성함. 응답 완료·취소·실패 후에는 주입이 자동으로 지워짐.

## 알아둘 점 (버전 호환성)

`index.js` 상단의 import 경로(`extensions.js`, `script.js`)와 `setExtensionPrompt`,
`callGenericPopup`, `generateQuietPrompt`, `generate` 같은 API는 SillyTavern 버전에 따라 시그니처가 조금씩 바뀔 수 있음.
확장 설치 후 브라우저 콘솔(F12)에 에러가 뜨면, 해당 함수/경로가 현재 설치된 ST 버전에서도
동일하게 존재하는지 `public/scripts/script.js`, `public/scripts/extensions.js`를 열어 확인할 것.
