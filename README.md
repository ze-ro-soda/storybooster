# 📖 스토리부스터 (StoryBooster)

스토리부스터는 SillyTavern 롤플레이의 **장르감·캐릭터성·플롯 전개**를 보조하는 확장 프로그램입니다.

- **장르 부스터**: 선택한 장르의 분위기와 표현을 꾸준히 강화합니다.
- **캐릭터 부스터**: 캐릭터의 성격·말투·행동·관계 반응을 보강합니다.
- **플롯 부스터**: 현재 대화에 맞는 사건이나 다음 전개를 필요할 때 생성합니다.

각 기능은 전역 설정에서 따로 켜거나 끌 수 있습니다.

현재 버전: **1.7.3**

## 10월 11일 업데이트 (v1.7.3)

- 기본 진단 응답 형식 및 재시도 처리 개선
- 오류 진단 로그 상세 정보 보강
- Jev 연결 안내 문구 정리

판정 기준·보정 정책·키 저장 방식은 기존과 같습니다. 모델별 응답 형식 호환성은 사용 환경에 따라 달라질 수 있습니다.

## 10월 6일 업데이트 (v1.7.2)

- Jev API 키를 브라우저에 평문 저장하도록 변경
- 암호화 기능이 제한된 HTTP 접속 환경의 키 저장·복원 개선
- 기존 암호화 키 자동 이전 및 저장·삭제 처리 안정화

추가 서버 플러그인 없이 사용할 수 있습니다. 키 저장 방식만 변경되며 진단·보정 기능은 기존과 같습니다.

## 10월 5일 업데이트 (v1.7.1)

- 기본 진단과 Jev의 대화 입력·판정·보정 기준 통일
- 기본 진단의 JSON 요청 호환성 개선 및 재시도 기록 보강
- 문장 구조·문구 반복의 비교 근거와 장면별 캐릭터 판정 개선
- 보정 우선순위·작성 기준·실패 복구 처리 정리
- 저장·응답 처리·비동기 플롯 적용 오류 수정 및 안정성 강화

## 1.7.0 주요 업데이트

- **Jev 진단 추가**: 장르·캐릭터를 세부 질문과 응답별 근거로 진단하는 선택 기능입니다. 판단 이유와 보정문은 설정한 진단 모델이 작성합니다.
- **진단·보정 정리**: 확인된 작은 문제는 주의와 가벼운 보정으로, 근거 부족·상충은 판단 보류로 구분합니다. 기본 진단과 Jev의 작성 요청 출력 한도를 4,800토큰으로 통일했습니다.
- **표현 반복 점검**: 문장 구조·단어·문구·묘사·마무리의 기계적인 반복을 확인하고 고유 말투와 자연스러운 반복은 허용합니다.
- **자동 랜덤박스 추가**: 채팅별 허용 후 자동 진단 주기에 맞춰 사건 필요성을 확인하며 준비 알림과 이번 후보 취소 기능을 제공합니다.
- **저장·화면 개선**: Jev 키 저장·복원과 준비 상태 표시, 장르 추천 적용·취소, 캐릭터 기준 백업·복원, 진단 기록과 오류 확인을 정리했습니다.

Jev와 자동 랜덤박스는 기본값이 꺼짐이며 사용자가 각각 켜서 사용할 수 있습니다.

## 설치

ZIP으로 직접 설치하거나 기존 스토리부스터 폴더에 업데이트할 수 있습니다.

1. 기존 확장 파일과 SillyTavern 설정을 백업합니다.
2. ZIP을 압축 해제한 뒤 `manifest.json`과 `index.js`가 있는 위치의 **내용 전체**를 현재 스토리부스터 확장 폴더에 복사합니다. `app`, `core`, `features`, `ui`도 함께 복사합니다.
3. SillyTavern을 새로고침합니다. 스토리부스터를 여러 폴더에 중복 설치해 동시에 활성화하지 않습니다.
4. 채팅 입력창의 마법봉 메뉴에서 스토리부스터를 엽니다.

기본 사용자 설치 위치의 예는 `SillyTavern/data/default-user/extensions/storybooster`입니다. 실제 사용 중인 폴더 바로 안에 `manifest.json`, `index.js`, `style.css`와 네 개의 하위 폴더가 있어야 합니다. 이 배포 파일의 자동 업데이트는 꺼져 있습니다.

## 빠른 사용법

1. **장르 부스터**에서 주 장르와 필요한 보조 장르를 선택합니다.
2. **캐릭터 부스터**는 캐릭터 기준을 생성·확인하고 전용 앵커를 준비합니다.
3. 다음 전개가 필요할 때 **플롯 부스터**에서 카테고리 또는 내 아이디어를 선택해 생성합니다.

파란색 `부스팅 중` 표시가 나타나면 해당 부스터 지침이 캐릭터 응답에 적용되고 있는 상태입니다.

## 기능 안내

### 장르 부스터

주 장르는 장면의 중심 의미와 전개 방향을, 보조 장르는 분위기·관계 압력·세계의 질감을 보강합니다. 기존 프리셋이나 작가 노트의 설정을 삭제하지 않고 별도 지침으로 적용됩니다.

- 주·보조 장르 선택 및 사용자 장르 추가
- 현재 롤플 장르 추천 및 추천 적용·취소
- 수동·자동 장르 진단
- 확인된 주의·약화·이탈 항목의 다음 응답 1회 보강

### 캐릭터 부스터

캐릭터 카드의 설명·성격·대화 예시를 바탕으로 성격, 가치관, 동기, 행동, 말투, 관계 반응 등의 기준을 정리합니다. 항목별 수정·재생성·핀 고정이 가능하며, 최신 전용 앵커가 준비되면 부스팅을 시작합니다.

캐릭터 기준은 **원본과 여러 갱신본**으로 보관할 수 있습니다. 원본에서 항목을 수정·재생성하거나 앵커를 바꾸면 원본을 덮어쓰지 않고 새 갱신본으로 저장합니다. 변화 탐색이 필요하지 않으면 현재 기준과 앵커를 AI 호출 없이 그대로 복사한 뒤 이름이나 내용을 직접 수정할 수 있습니다. 사용자가 캐릭터의 변화 방향을 적으면 현재 기준과 최근 AI 답변 20개(각 답변 직전의 유저 입력 포함)를 참고해 새 갱신안을 만듭니다. 최근 롤플은 요청을 거절하는 심사 자료가 아니라 변화의 표현·범위·강도를 구체화하는 자료로 사용합니다. 방향을 직접 지정하지 않는 보수적인 자동 변화 탐색도 별도로 제공됩니다. 제안은 자동 적용되지 않으며, 사용자가 항목별로 선택·수정한 뒤 완성된 새 기준과 앵커로 저장합니다. 각 채팅에서는 선택한 한 버전만 진단과 부스팅에 사용합니다.

매 응답에는 기준 전체가 아니라 **짧은 캐릭터 전용 앵커와 공통 보강 규칙만 사용**해 입력 토큰을 줄입니다. 캐릭터 카드의 설명·성격·대화 예시가 바뀌면 재확인 안내를 표시하지만, 기존 기준과 앵커의 부스팅은 중단하지 않습니다. 이 알림은 전역 설정에서 끌 수 있습니다.

출력 언어가 한국어이면 기준과 앵커를 한국어로 표시하되 실제 부스팅에는 영문 앵커를 사용합니다. 한국어 앵커를 직접 수정해 저장할 때는 영문 주입본을 만들기 위해 분석 프로필을 한 번 사용합니다.

- 캐릭터 기준 생성·수정 및 전용 앵커 갱신
- 원본 보존 및 갱신본 최대 10개 보관, 갱신본 이름 변경 및 채팅별 사용 버전 선택
- 현재 기준과 앵커를 그대로 복사한 수동 편집용 새 버전 생성
- 사용자 지정 변화 방향과 최근 롤플 20개를 반영한 AI 갱신안 생성
- 최근 롤플의 지속적인 변화만 찾는 보조 자동 탐색
- 변경·유지 항목과 최근 롤플 근거 수준을 확인하고 수정한 뒤 새 버전 저장
- 캐릭터 카드 변경 감지와 기존 기준 유지 선택
- 앵커 직접 편집·취소 및 마지막 저장 시간 표시
- 캐릭터성·해석·능동성·관계·연속성·표현 반복 진단
- 확인된 주의·약화·이탈 항목의 다음 응답 1회 보강

### 플롯 부스터

현재 대화와 선택한 카테고리를 바탕으로 완성된 롤플 답변이 아닌 **다음 전개용 플롯**을 생성합니다.

- 카테고리 자유 생성 또는 내 아이디어 다듬기
- 현재 결과 다듬기와 다른 방향 생성
- 입력창에 넣기 또는 주입 후 AI 응답 생성
- 채팅별 최근 추천 최대 5개 보관
- 채팅별 **비밀모드**: 선택한 카테고리에 맞는 사건을 플롯 공개 없이 바로 전개
- **랜덤박스**: 카테고리와 결과를 숨긴 채 무작위 사건 전개
- **미친 랜덤박스**: 현재 흐름과 개연성을 벗어난 예측 불가능한 전개까지 허용
- **캐릭터의 질문박스**: 현재 장면을 유지한 채 주제 제한 없이 예측할 수 없는 질문을 마지막 장면으로 생성

수동 플롯 후보는 장르 부스터 선택값을 직접 전달받지 않으며 현재 대화와 선택 카테고리를 우선합니다. 새 자동 랜덤박스 경로는 선택한 주 장르도 참고합니다. 최신 캐릭터 전용 앵커가 있으면 캐릭터 일관성을 위한 참고 자료로 사용합니다.

비밀모드는 채팅마다 따로 켜며 기본값은 꺼짐입니다. 비밀모드로 생성한 플롯도 응답 후 최근 추천에서 확인할 수 있습니다. 랜덤박스와 미친 랜덤박스는 비밀모드에서만 표시됩니다. 캐릭터의 질문박스는 별도의 플롯 분석 호출 없이 현재 채팅 연결이 바로 작성합니다.

### 캐릭터 기준 백업·복원

캐릭터 탭의 **기준 백업·복원**에서 현재 캐릭터의 원본·갱신본·핀 고정·상시 앵커를 JSON 파일로 보관할 수 있습니다. **백업 파일 저장**을 누르면 다운로드가 시작됩니다. 기준에 적힌 내용은 포함되므로 공유 전 파일 내용을 확인해 주세요. API 키·연결 설정·대화 기록은 백업하지 않습니다.

**백업 가져오기**로 파일을 선택한 뒤 항목별 내용을 펼쳐 확인하고, 가져올 항목만 선택해 **선택 항목 가져오기**를 누릅니다. 원본이 비어 있으면 백업의 원본을 복원하며, 이미 원본이 있으면 새 갱신본으로 추가합니다. 기존 내용과 동일한 항목은 건너뛰고 같은 이름은 구분되는 이름으로 저장합니다. 갱신본 최대 10개 제한을 넘으면 항목을 줄여야 하며 기존 기준을 덮어쓰거나 삭제하지 않습니다. 기준 문구 속 인물 이름은 자동으로 바꾸지 않습니다.

가져온 갱신본은 위의 기준 선택 목록에서 골라 사용합니다. 비어 있던 원본을 복원하면 원본을 선택한 채팅에서 그 기준을 사용할 수 있습니다. 앵커가 없거나 재생성이 필요한 기준은 기존 방식으로 앵커를 갱신합니다. 파일을 선택하거나 미리 보는 것만으로는 저장되지 않습니다.

### 문제 발생 시

전역 설정의 오류 로그나 개발자 도구의 **진단 진행 기록 → 기록 복사**로 실패한 단계와 재시도 여부를 확인할 수 있습니다. 진행 기록에는 API 키·롤플 원문·캐릭터 기준·채팅 이름·접속 주소를 넣지 않습니다. 일반 자동·수동 진단의 기록도 수집합니다. 개발자 도구 사용법과 상세 구현·검증 이력은 `INTERNALS.md`, `JEV-DEVELOPMENT.md`를 참고해 주세요.

### 진단 결과 확인

최근 진단 결과에 **실제로 분석한 AI 답변 수**와 **진단 당시 선택한 캐릭터 기준 이름**을 표시합니다. 이전 버전에서 저장한 결과에는 이 정보가 없을 수 있습니다.

채팅별 최근 완료 진단 최대 6개를 간단히 보관합니다. 진단 범위·장르/캐릭터 기준·진단 엔진과 모델이 같고, 보정이 실제 반영된 뒤 이전 진단 범위와 겹치지 않는 답변이 쌓였을 때 항목별 비교 문구가 나타납니다. 이전 답변이 수정되거나 기준이 바뀌면 비교를 건너뜁니다. 비교는 새 진단이 끝난 뒤 코드에서 처리하며 AI에게 이전 판정을 전달하지 않습니다. 같은 항목에서 문제가 다시 감지됐는지 보여주는 참고 정보이며, 보정 효과나 같은 세부 원인임을 단정하거나 보정 강도를 자동으로 높이지 않습니다.

자동 랜덤박스 상태에는 조용한 진전·기존 사건 진행·유저 입력 우선·보정 우선·판단 근거 부족 등 사건을 넣지 않은 이유를 기존 한 줄 안내에 표시합니다.

### Jev 진단 · 선택 기능

전역 확장 설정의 **Jev 진단**에서 안내를 확인하고 `안내에 동의하고 자동·수동 진단에 Jev 사용`을 체크한 뒤, API 키를 입력하고 `키 저장` → `연결 테스트`를 누릅니다. 사용 동의가 해제되어 있으면 안내를 확인하고 다시 체크합니다. 연결 테스트는 짧은 예문만 사용하며 실제 롤플을 보내지 않습니다.

- Jev가 활성화된 항목마다 6개의 세부 질문을 독립적으로 판단하고, 그 결과를 바탕으로 항목 판정과 응답별 근거를 확인합니다. 모든 장르·캐릭터 항목이 활성화되면 세부 질문 60개이며, 항목·근거 확인은 별도 단계입니다. 최근 AI 답변 최대 10개와 각 답변 직전의 유저 입력을 참고합니다.
- 약화·이탈의 기존 근거 개수 검증과 보정 항목 최대 2개, 다음 응답 1회 적용 규칙을 유지합니다. 독립 세부 관찰과 실제 응답 근거에서 확인된 가벼운 문제는 `주의`로 표시하고 비례하는 보정을 넣습니다. 정보 부족·상충·낮은 확신은 `판단 보류`로 구분하고 자동 보정 대상에서 제외합니다. 자연스러운 성장·관계 한정 변화·일시적인 반응을 곧바로 캐릭터 이탈로 보지 않도록 질문합니다.
- 약화·이탈을 주의보다 먼저 선택하며, 같은 심각도에서는 다음 응답에 미치는 영향 → 문제가 확인된 서로 다른 답변 수 → 판정 확신도 순으로 최대 2개를 고릅니다. 마지막 동률은 고정 항목 순서를 사용합니다.
- 판단 이유와 필요한 장르·캐릭터 맞춤 보정문, 화면의 `다음 보정` 설명을 기존 진단 연결 프로필의 모델에 함께 요청합니다. 확인된 문제만 보정하며 정상적인 특성과 자연스러운 변화를 유지하도록 지시합니다. 작성 실패 시 기존 대체 보정 지시를 사용하고 설명 작성 실패를 알립니다. 캐릭터 기준·앵커·플롯 생성 모델은 바뀌지 않습니다.
- 기존 항목별 결과 화면을 유지하고, 장르·캐릭터 탭에 Jev 연결 상태를 표시합니다. 연결 여부와 이번 진단에 실제 사용한 엔진은 구분합니다.
- 키 없음·사용 해제·Jev 요청 실패 시에는 기존 장르·캐릭터 진단을 사용합니다. 진단 결과에서 사용한 연결과 Jev 실패 후 전환 여부를 확인할 수 있습니다.

**키는 현재 브라우저의 사이트 저장소(localStorage)에 평문으로 저장됩니다.** 같은 브라우저·SillyTavern 접속 주소·계정에서는 새로고침과 실리 서버 재시작 후 자동으로 불러옵니다. 별도의 서버 플러그인이나 암호화 기능은 필요하지 않으며, HTTP 접속에서도 브라우저가 사이트 저장소를 허용하면 저장할 수 있습니다. 저장 직후 다시 읽어 확인하고, 실패하면 오류를 표시하며 입력값을 유지합니다.

- 다른 브라우저·기기·접속 주소에서는 키를 다시 입력해야 합니다. 기기 간 동기화는 하지 않습니다. 브라우저 데이터를 삭제하면 키도 사라집니다.
- 평문 저장이므로 같은 사이트의 스크립트나 브라우저 저장소에 접근할 수 있는 사람은 키를 읽을 수 있습니다. 확장 설정·채팅·진단 보고서에는 키를 넣지 않습니다.
- 기존 암호화 키는 HTTPS 또는 localhost 등 복호화 가능한 환경에서 자동으로 이전합니다. 복호화 기능을 사용할 수 없거나 접속 주소가 바뀐 경우에는 키를 한 번 다시 입력해 주세요.
- `키 삭제`는 현재 주소·계정의 키를 삭제하고, 이전 암호화 키의 재복원을 막는 키 없는 표시만 남깁니다. 다른 계정의 키는 유지합니다. Jev 사용 해제는 저장본을 지우지 않습니다.
- ‘Jev 사용 준비됨’은 키를 사용할 준비가 됐다는 뜻입니다. 매번 연결 테스트를 누를 필요는 없으며 실제 연결 성공 여부는 요청 때 확인합니다.

요청은 기존 SillyTavern 서버가 중계합니다. 추가 서버 플러그인이나 CORS 프록시 설정은 필요하지 않습니다. 지원 여부는 연결 테스트로 확인합니다. 진단 시 분석할 롤플 내용과 선택한 기준이 Jev에 전송되며 API 비용이 발생합니다.

### 자동 랜덤박스 · 채팅별 선택 기능

플롯 탭의 `자동 랜덤박스`에서 **이 채팅에서 자동 랜덤박스 허용**을 체크합니다. 준비 알림 후 **이번 랜덤박스 취소**를 누르면 이번 후보만 버리고 허용 설정은 유지합니다. 전역 플롯 부스터와 자동 진단 주기도 켜져 있어야 합니다.

확인된 장르·캐릭터 문제는 보정을 우선합니다. 판단 보류만 있다면 항목 종류나 개수와 관계없이 별도 플롯 판단으로 사건 필요성을 확인합니다. 보류를 정상 판정으로 바꾸지는 않습니다. 실제 전개 정체와 자연스러운 삽입 적합성이 확인될 때만 일반 랜덤박스 후보를 준비합니다. 플롯 판단에 필요한 현재 상황·유저 의도가 불명확하거나 조용한 일상·감정 교류가 진행 중인 경우, 기존 사건의 다음 단계가 남아 있는 경우에는 준비를 미룹니다. 미친 랜덤박스와 질문박스는 자동으로 사용하지 않습니다.

후보를 준비해도 즉시 롤플 답변을 생성하지 않습니다. **다음 일반 응답 직전에 새 유저 입력과 후보의 적합성을 다시 확인**하고, 통과한 경우에만 1회 주입합니다. 유저의 직접적인 행동·질문·진행 방향이 우선입니다. 검사 실패·시간 초과·불확실한 판정이면 사건 없이 응답을 진행합니다. 채팅 전환·기준 변경·수동 플롯·허용 해제 시 대기 후보를 취소합니다.

별도 재발동 간격 설정 없이 전역 자동 진단 주기에 맞춰 확인합니다. 마지막 반영 후 최소 한 진단 주기가 지나야 다시 후보를 준비합니다. 수동 진단에서는 자동 사건을 준비하거나 적용하지 않습니다.

## 전역 설정

- 장르·캐릭터·플롯 부스터 사용 여부
- Jev 진단 사용 여부, 키 저장·삭제·연결 테스트
- 장르/캐릭터 분석 연결 프로필
- 플롯 생성 연결 프로필
- 자동 진단 주기: 끄기 또는 캐릭터 응답 5~15회, 기본 10회
- 플롯 생성 토큰: 기본 1200
- 출력 언어: 한국어 또는 English
- 캐릭터 시트 변경 알림 사용 여부
- 현재 채팅방의 주입 프롬프트·글자 수·토큰 수 확인
- 최근 오류 진단 로그 3건 확인·복사·삭제

별도 프로필을 지정하지 않으면 현재 채팅의 기본 연결을 사용합니다. 지정한 프로필을 사용할 수 없을 때는 다른 연결로 자동 전환하지 않고 오류를 표시합니다. `주입 후 AI 응답 생성`의 실제 롤플 답변은 현재 채팅 연결로 생성합니다.

## AI 호출 및 주의사항

장르·캐릭터 부스팅 자체에는 **별도 AI 호출이 발생하지 않습니다.** 장르 추천·진단, 캐릭터 기준·앵커 생성, 캐릭터 갱신안 생성·저장, 플롯 생성 작업에서만 추가 호출이 발생합니다. 캐릭터 갱신안은 정상 응답 기준으로 제안 생성에 한 번, 승인 후 새 앵커 생성에 한 번 호출합니다. `현재 기준 복사본 만들기`는 저장된 기준과 앵커를 그대로 복사하므로 AI를 호출하지 않습니다. 빈 응답·잘림·필수 필드 오류 등 구조화 출력 호환 문제가 있으면 각 요청 단계에서 최대 두 번 추가 호출할 수 있습니다.

플롯 후보 생성은 호환 재시도와 형식·언어 보정을 **모두 합쳐 최대 3회**까지만 호출합니다. 이 안에 정상 결과를 얻지 못하면 추가 호출을 중단하고 오류를 표시하며, 잘못된 후보를 저장하거나 주입하지 않습니다. 이후 실제 롤플 답변 생성은 별도 호출입니다. 자동 호출을 원하지 않으면 전역 설정에서 자동 진단을 끌 수 있습니다.

Jev 진단은 항목 판정과 응답별 근거 확인에 보통 최대 2회 요청을 사용합니다. 보정 여부와 관계없이 기존 진단 모델의 판단 이유 작성 호출 1회가 추가되며, 필요한 보정문과 다음 보정 설명은 이 호출에 함께 포함됩니다. 자동 랜덤박스는 필요성 판단, 사건 후보 생성, 다음 응답 직전 확인에 추가 호출을 사용하므로 비용과 대기 시간이 늘 수 있습니다. 기존 모델의 구조화 응답 복구도 별도 요청을 사용할 수 있습니다. Jev 확률·신뢰도 기준은 판정에 사용할 근거를 고르는 기준이며 실사용 정확도를 보장하는 수치가 아닙니다.

- 모델과 연결 제공자에 따라 출력 품질과 JSON 준수 정도가 달라질 수 있습니다.
- 장르·캐릭터 분석과 플롯 후보 생성은 개별 API 요청마다 3분 제한을 적용하고, 시간 초과 시 가능한 연결에는 중단을 요청합니다. 재시도가 있으면 작업 전체 소요 시간은 더 길어질 수 있습니다.
- 플롯 주입 후 현재 채팅 연결로 생성하는 실제 롤플 응답이 10분 안에 끝나지 않으면 중단을 요청하며, 자동 중단 기능을 찾지 못한 경우 별도로 안내합니다.
- `MAX_TOKENS`나 잘림 오류가 반복되면 플롯 생성 토큰 또는 연결 프로필의 출력 한도를 확인합니다.
- NSFW를 포함한 출력 범위는 사용 중인 모델과 제공자의 정책을 따릅니다.
- 그룹 채팅에서는 캐릭터 기준 기능을 사용할 수 없습니다.

기본 진단과 Jev는 최근 AI 답변 최대 10개와 각 답변 직전의 유저 입력을 함께 확인하며, 전체 길이 한도에 맞춰 오래된 대화 쌍부터 제외합니다. 기본 진단의 입력 토큰은 이전보다 늘 수 있습니다. Jev에서 표현 반복 문제가 발견되면 기존 근거 요청에 비교 대상·반복 유형 질문을 함께 넣으며 요청 단계는 늘리지 않습니다. 비교 질문이 추가되면 해당 요청의 토큰 사용량은 늘 수 있습니다. 두 엔진은 공통 기준을 사용하지만 모델과 판정 방식이 달라 결과가 항상 같지는 않습니다.

기본 진단과 Jev 이유·보정문 작성의 첫 요청·호환 재시도는 모두 최대 4,800토큰을 허용합니다. 실제 출력량과 소요 시간은 모델에 따라 달라집니다. 기본 진단은 판정·이유·보정문을 한 요청에서 함께 작성합니다.
