# 📖 스토리부스터 (StoryBooster)

SillyTavern 롤플레이의 **장르감·캐릭터성·다음 전개**를 보조하는 확장입니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 장르 부스터 | 주·보조 장르 선택, 장르 추천, 수동·자동 진단 |
| 캐릭터 부스터 | 캐릭터 기준 생성·갱신·편집, 저장 버전 비교와 항목 복사 |
| 플롯 부스터 | 사건·전개 아이디어 생성, 아이디어 보관함, 자동 랜덤박스 |

진단에서 확인된 문제는 다음 응답에 한 번 보강합니다. 각 부스터는 따로 켜거나 끌 수 있습니다.

## 설치·업데이트

1. 기존 확장과 설정을 백업합니다.
2. 배포 ZIP을 풀고, 안쪽 `storybooster` 폴더의 내용을 스토리부스터 설치 폴더에 복사합니다. `manifest.json`, `index.js`와 `app`, `core`, `features`, `ui` 폴더를 함께 넣어 주세요.
3. SillyTavern을 새로고침한 뒤 채팅 입력창의 **마법봉 메뉴 → 스토리부스터**를 엽니다.

같은 확장을 여러 폴더에 중복 설치하지 마세요.

## 빠른 사용법

- **장르**: 주 장르와 필요한 보조 장르를 선택합니다.
- **캐릭터**: 기준을 생성·검토하고 전용 앵커를 준비합니다.
- **플롯**: 카테고리나 내 아이디어로 다음 전개를 생성합니다.

자동 랜덤박스는 플롯 탭에서 채팅별로 허용합니다. 전역 플롯 부스터와 자동 진단 주기도 켜져 있어야 합니다. 준비된 후보는 취소할 수 있습니다.

## Jev 연결 · 선택 사항

1. 전역 확장 설정의 **Jev 진단**에서 사용 안내에 동의합니다.
2. **Typesafe** 또는 **NanoGPT**를 선택하고 해당 제공자의 API 키를 입력합니다.
3. **키 저장 → 연결 테스트**를 진행합니다. 새로고침할 때마다 다시 테스트할 필요는 없습니다.

연결하면 기존 자동·수동 진단의 판정을 Jev로 진행합니다. 판단 이유와 보정문은 기존 진단 연결 모델이 작성합니다. Jev를 연결하지 않아도 기본 진단을 사용할 수 있습니다.

요청은 기존 SillyTavern 서버가 중계하며 추가 서버 플러그인은 필요하지 않습니다. 진단할 롤플 내용과 선택 기준이 제공자에 전송되고 API 비용이 발생합니다.

**API 키는 이 브라우저에 평문 저장됩니다.** 기존 암호화 키도 복호화 가능한 환경에서 평문 저장본으로 자동 이전됩니다. 다른 기기·브라우저·접속 주소를 쓰거나 브라우저 데이터를 삭제하면 다시 입력해야 합니다. 키는 확장 설정·채팅·진단 보고서에 포함하지 않습니다.
