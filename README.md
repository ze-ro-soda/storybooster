# 🎭 스토리부스터 (StoryBooster)

SillyTavern 롤플의 장르감과 캐릭터성을 유지하고, 필요할 때 현재 장면에 어울리는 플롯을 생성하는 확장입니다.

- **장르 부스터**: 선택한 장르의 정체성·분위기·표현과 장면 밀도를 강화합니다.
- **캐릭터 부스터**: 캐릭터의 성격·대사·행동·관계 반응을 살리고 설정 이탈과 해석 편향을 점검합니다.
- **플롯 부스터**: 사용자가 원할 때만 현재 롤플에 맞는 사건이나 다음 전개를 생성합니다.

세 부스터는 별도 탭으로 나뉘며 전역 설정에서 각각 완전히 끌 수 있습니다. 기능을 꺼도 저장된 장르·캐릭터 기준·플롯 기록은 삭제되지 않습니다. 장르와 캐릭터 부스터를 함께 사용해도 자동 진단은 한 번의 AI 요청으로 처리합니다.

## 주요 기능

### 🎭 장르 부스터

- 주 장르 1개와 보조 장르 1개 선택
- 장르 고유의 분위기, 표현 방식과 장면 밀도 강화
- 장르마다 정체성·구체 신호·관계 효과·질감·혼동 방지 기준을 구분해 비슷한 장르 사이의 차이 강화
- 현재 롤플을 분석한 AI 장르 추천
- 사용자 장르 직접 추가
- 주 장르·보조 렌즈·장르 표현·장면 밀도를 구분한 자동 또는 수동 장르 드리프트 진단
- 최근 진단에서 약화된 항목과 적용한 보정 확인
- 다음 응답에 적용되기 전 진단 보정 취소

주 장르는 캐릭터의 동기, 선택, 관계 행동과 장면의 중심 의미를 담당합니다. 보조 장르는 현재 장면에 자연스러운 적용 기회가 있을 때만 관계 압력, 세계관 논리, 분위기와 묘사 질감을 보강합니다. 사건은 캐릭터의 동기·장르 논리·현재 상황에서 자연스럽게 생길 수 있지만, 선택한 장르를 보여주기 위해 반드시 만들지는 않습니다.

진단의 `장르 표현`은 묘사·대사와 행동의 강조점·사건 진행·속도와 결과가 선택한 장르답게 드러나는지를 확인합니다. `장면 밀도`는 장르 정체성과 별개로 공간·감각·행동·사회적 상황이 현재 행동과 감정에 작용해 장면이 평평한 요약처럼 흐르지 않는지를 확인합니다. 단순히 문장이 길거나 장식적인 묘사가 많다고 안정으로 판정하지 않습니다.

상시 장르 앵커는 장르별 상세 기준 전체를 매번 보내지 않습니다. 실제 응답에 필요한 압축 지시만 사용하고, 풍부한 구분 기준은 장르 추천과 진단에서 활용해 토큰 부담을 줄였습니다.

기본 장르에는 로맨스, 롬콤, 일상, 드라마, 미스터리, 액션, 범죄, 판타지, SF, 공포, 코미디, 앵스트, 다크, 데드 도브, 느와르, 사이버펑크, 섹텐, 욕망, NSFW 등이 포함되어 있습니다. 화면에는 한국어로 표시되며 AI에는 영어 지침으로 전달됩니다.

- **롬콤**: 로맨스의 관계 진전을 중심에 두고, 캐릭터다운 엇갈림·타이밍·후폭풍이 웃음과 친밀감의 변화를 함께 만들도록 합니다. 단순 코미디나 농담이 섞인 로맨스와 구분합니다.
- **앵스트**: 상실·죄책감·두려움·그리움 같은 지속적인 정서적 고통이 캐릭터의 선택과 관계에 압력을 주도록 합니다. 비극적 결말, 멜랑콜리한 문체, 반복적인 슬픔과 구분합니다.
- **데드 도브**: 캐릭터 카드·시나리오·태그·기존 롤플에 이미 설정된 불편하거나 금기적인 소재를 순화·미화·자동 면죄하지 않고 명시된 무게와 결과를 유지합니다. 선택만으로 새로운 금기나 폭력 수위를 만들거나 강제로 악화시키지는 않습니다.
- **NSFW**: 성인 캐릭터 사이의 성적 장면이 시작되면 생략·암전·완곡한 요약 없이 신체·공간·감각·감정의 연속성을 유지해 충분히 이어갑니다.

장르를 선택하면 주·보조 장르가 실제로 무엇을 강화하는지 짧은 한국어 설명을 함께 표시합니다.

### 👤 캐릭터 부스터

- 캐릭터 시트를 한 번 분석해 7개의 짧은 `캐릭터 기준`으로 저장
- 전체 분석과 같은 호출에서 짧은 영문 `캐릭터 전용 상시 앵커` 생성
- 항목별 직접 편집·자동 저장·편집 잠금·다시 생성
- 핀으로 원하는 항목을 고정한 채 나머지만 전체 다시 요약
- 저장된 기준 전체 삭제
- 캐릭터성·캐릭터 해석·능동성·관계 반응·연속성·표현 다양성 진단
- 약화된 항목만 다음 응답 한 번에 보정
- 캐릭터 관련 보정에는 가장 연관된 캐릭터 기준을 최대 2개만 일회성으로 사용

캐릭터 기준은 `핵심 정체성`, `성격·특성`, `가치관·경계`, `목표·동기`, `행동·의사결정`, `대사·감정 표현`, `관계 반응`으로 나뉩니다. 기준이 하나라도 저장되면 캐릭터 부스터의 상시 보강이 시작되고, 기준을 모두 비우거나 삭제하면 해제됩니다. 전체 분석과 AI 항목 재생성에서는 같은 요청 안에서 캐릭터별 영문 상시 앵커도 갱신하므로 별도 호출이 추가되지 않습니다.

매 응답에는 최대 700자의 캐릭터 전용 앵커와 압축된 공통 보강 규칙만 사용합니다. 기준 7개 전체나 캐릭터 시트를 확장이 매번 다시 넣지는 않습니다. 공통 규칙은 캐릭터성·가치관·경계·말투·능동성·관계 기억·연속성·표현 다양성을 보강하고, 펠소의 최근 말과 행동을 의미 없이 반복하거나 바꿔 말하는 것으로 응답을 채우지 않도록 합니다. 사용자가 기준을 직접 수정하면 앵커는 `갱신 필요`로 표시되며 직접 편집하거나 현재 기준으로 다시 만들 수 있습니다.

캐릭터 시트는 전체 또는 개별 항목을 요약할 때만 선택한 연결 프로필로 전송되며, 한 번에 최대 24,000자까지만 분석합니다. 캐릭터 관련 보정이 필요할 때만 진단이 고른 관련 기준을 최대 2개까지 다음 응답 한 번에 함께 사용합니다. 기준은 같은 캐릭터의 다른 채팅에서도 재사용되며, 캐릭터 시트가 바뀌면 기존 수정본을 자동으로 덮어쓰지 않고 `갱신 필요` 상태로 알려줍니다.

- **캐릭터성**: 설정과 다른 대사·행동·가치관·경계가 반복되는지 확인합니다.
- **캐릭터 해석**: 한 가지 성향, 지나친 긍정·부정 방향 또는 흔한 전형으로 캐릭터를 몰아가는지 확인합니다.
- **능동성**: 캐릭터가 자신의 동기에 따라 선택하고 장면에 영향을 주는지 확인합니다.
- **관계 반응**: 기존 관계의 기억·신뢰·긴장·경계가 반응에 이어지는지 확인합니다.
- **연속성**: 진행 중인 행동·대화·감정과 즉각적인 결과가 이어지는지 확인합니다.
- **표현 다양성**: 같은 몸짓·이미지·문장 패턴·관계 흐름이 반복되는지 확인합니다.

의도적인 단순 성향이나 강한 캐릭터성 자체를 문제로 보지 않습니다. 자연스러운 성장·퇴행, 거짓말, 위장, 관계에 따른 태도 차이와 극단적인 상황의 일시적 반응도 자동으로 캐릭터 붕괴로 판정하지 않습니다.

### 🔍 추천과 통합 진단

- **현재 롤플 분석**: 최근 메시지를 읽고 주 장르와 보조 장르를 추천합니다.
- **장르 지금 진단하기**: 장르 탭에서 주 장르·보조 렌즈·장르 표현·장면 밀도만 점검합니다.
- **캐릭터 지금 진단하기**: 캐릭터 탭에서 캐릭터 관련 항목만 점검합니다.
- **자동 진단**: 확장 관리의 전역 설정에서 캐릭터 응답 5~15회마다 진단하도록 설정할 수 있습니다.
- **자동 진단 끄기**: 추가 호출 없이 상시 장르·캐릭터 부스터만 사용할 수 있습니다.

추천 결과는 자동으로 적용되지 않습니다. 사용자가 `추천 적용`을 눌러야 현재 채팅의 장르가 변경됩니다.

자동 진단은 활성화된 장르와 캐릭터를 한 번의 요청으로 함께 확인합니다. 수동 진단은 누른 탭의 기준·지시·출력 항목만 전송해 다른 분야를 분석하지 않으며, 최근 진단 결과도 장르와 캐릭터 탭에 따로 보존됩니다. 약한 부분이 발견되면 해당 진단에서 우선순위가 높은 항목을 최대 2개만 다음 캐릭터 응답 1회에 보정합니다. 캐릭터성·캐릭터 해석·능동성·관계 반응이 보정 대상으로 선택되면 저장된 캐릭터 기준 중 직접 관련된 항목도 최대 2개만 같은 일회성 보정에 포함됩니다. 장르 탭에서는 `주 장르·보조 렌즈·장르 표현·장면 밀도`, 캐릭터 탭에서는 `캐릭터성·캐릭터 해석·능동성·관계 반응·연속성·표현 다양성`을 확인할 수 있습니다. 보조 렌즈의 `대기`는 현재 장면에 자연스러운 적용 기회가 없어 보정하지 않는 상태이며, 캐릭터 기준이 없으면 캐릭터 부스터와 캐릭터 진단이 시작되지 않습니다.

보정이 아직 적용되기 전이라면 `이번 보정 적용 안 하기`를 눌러 일회성 보정만 취소할 수 있습니다. 진단 기록과 상시 장르 부스터, 추가 호출 없는 `DRIFT GUARD`는 그대로 유지됩니다. 진단이 실패하더라도 상시 장르 부스터는 계속 작동합니다.

### 🎲 플롯 부스터

#### 자유 생성

카테고리 하나를 선택하면 현재 롤플에 맞는 새로운 사건 후보를 생성합니다. 카테고리는 고정된 사건 목록이 아니라 생성 방향만 제시합니다.

- 정보·발견
- 비밀·단서
- 제3자 개입
- 목표·선택
- 갈등·장애
- 관계 변화
- 감정 표출
- 상황 변화
- 결과·후폭풍
- 일상·계기
- 세계·세력
- 돌발 변수

이모지, 이름과 생성 방향을 입력해 사용자 플롯 카테고리도 추가할 수 있습니다.

선택한 카테고리는 단순한 이름표로만 사용되지 않습니다. 추천은 최근 대화의 구체적인 사실을 사용하고, 정보·선택지·관계·압력 중 하나 이상을 실제로 바꾸며, 카테고리 이름을 지워도 방향을 알아볼 수 있도록 내부 점검을 거칩니다.

#### 내 아이디어

키워드나 대략적인 내용을 입력하면 핵심 의도는 유지하면서 현재 롤플의 인물, 관계, 세계관과 인과에 맞는 플롯으로 다듬어 줍니다.

`자유 생성`과 `내 아이디어`의 결과는 서로 섞이지 않으며 각 탭에 따로 유지됩니다.

#### 결과 활용

- **다듬기**: 현재 추천의 핵심 방향을 유지하며 구체성, 개연성, 장르감과 캐릭터 연관성을 개선합니다.
- **새 방향**: 현재 추천과 최근 기록의 반복·재표현을 피하고 다른 갈등, 계기, 전개와 결과를 생성합니다.
- **입력창에 넣기**: 결과를 채팅 입력창으로 옮겨 직접 수정한 뒤 전송할 수 있습니다.
- **주입 후 AI 응답 생성**: 플롯을 다음 응답에 한 번 주입하고 즉시 캐릭터 응답을 생성합니다.
- **결과 지우기**: 현재 탭에 표시된 결과만 지웁니다.

플롯 생성 결과는 완성된 롤플 장면이나 캐릭터의 직접 응답이 아니라, 앞으로 일어날 전개와 그 영향을 설명하는 짧은 기획안으로 요청됩니다. 일부 모델이 대사·행동문을 포함한 롤플 장면을 반환하면 이를 감지해 같은 사건의 핵심을 유지한 플롯 기획안 형식으로 한 번 자동 보정합니다. 보정 후에도 장면형 출력이 계속되면 잘못된 결과를 추천창에 표시하지 않고 오류를 안내합니다.

주입된 플롯은 모델이 OOC로 확인하거나 설명할 요청이 아니라 현재 장면 안에서 시작되는 전개로 전달됩니다.

각 채팅의 최근 플롯 추천은 최대 5개까지 자동으로 보관됩니다. 히스토리 아이콘을 눌러 목록을 펼친 뒤 `추천창으로 불러오기`를 눌러야 현재 결과창으로 이동합니다. 개별 삭제와 전체 삭제도 지원합니다.

4. 채팅 입력창의 마법봉 메뉴에서 `스토리부스터`를 선택합니다.

### 직접 설치

1. 배포 폴더를 SillyTavern의 아래 경로에 복사합니다.

   `SillyTavern/public/scripts/extensions/third-party/storybooster`

2. SillyTavern을 새로고침합니다.
3. 확장 관리 화면에서 스토리부스터가 활성화되어 있는지 확인합니다.

업데이트할 때는 기존 폴더의 파일을 새 버전으로 교체한 뒤 SillyTavern을 새로고침하세요. 이전 채팅별 설정과 사용자 장르는 가능한 범위에서 그대로 이전됩니다.

## 빠른 시작

1. 롤플 채팅을 엽니다.
2. 마법봉 메뉴에서 `스토리부스터`를 누릅니다.
3. 장르 부스터에서 주 장르를 선택합니다.
4. 캐릭터 부스터를 사용할 경우 캐릭터 시트를 한 번 요약해 기준을 만듭니다.
5. 필요하면 확장 관리에서 자동 진단 주기를 설정합니다. 기본값은 캐릭터 응답 10회입니다.
6. 사건이나 다음 전개가 필요할 때 플롯 부스터를 사용합니다.

장르 부스터는 한 번 선택하면 해당 채팅에서 계속 작동합니다. 플롯 부스터는 사용자가 버튼을 눌렀을 때만 사건을 생성합니다.

## 전역 설정

SillyTavern의 확장 관리 화면에서 다음 항목을 설정할 수 있습니다.

### 사용 기능

- `장르 부스터`, `캐릭터 부스터`, `플롯 부스터`를 각각 켜거나 끌 수 있습니다.
- 처음 설치하면 세 기능이 모두 켜져 있습니다.
- 기능을 꺼도 저장된 장르, 캐릭터 기준·앵커와 플롯 기록은 삭제되지 않습니다.
- 꺼진 기능은 상시 프롬프트와 일회성 주입에서 제외되며 해당 기능의 자동 진단·추천·생성 호출도 시작하지 않습니다.
- 기능을 다시 켜면 보존된 설정을 이어서 사용할 수 있습니다.

### 연결 프로필

두 작업군에 서로 다른 SillyTavern 연결 프로필을 사용할 수 있습니다.

- **장르/캐릭터 진단 프로필**: 장르 추천·진단과 캐릭터 기준·상시 앵커 생성에 사용합니다. 기본값이자 권장값은 현재 채팅 연결입니다.
- **플롯 프로필**: 자유 생성, 내 아이디어, 다듬기와 새 방향에만 사용합니다. 비교적 저렴한 별도 프로필을 선택할 수 있습니다.
- 각 항목에서 별도 프로필을 선택하지 않으면 현재 메인 채팅 연결을 사용합니다.
- 캐릭터의 일반 롤플 응답은 기존 메인 채팅 연결을 그대로 사용합니다.
- `주입 후 AI 응답 생성`에서도 플롯 후보까지만 플롯 프로필을 사용하고, 실제 캐릭터 응답은 현재 채팅 연결로 생성합니다.
- 요청이 시작되면 선택한 프로필을 재시도까지 고정하므로 작업 도중 설정을 바꿔도 진행 중인 요청에는 영향을 주지 않습니다.
- 생성이나 진단이 시작되면 채팅 내용과 선택 설정도 함께 고정합니다. 도중에 다른 채팅으로 이동해도 결과가 새 채팅에 섞이지 않습니다.
- 진단 중 주·보조 장르, 사용 기능 또는 캐릭터 기준이 바뀌면 이전 설정으로 만든 보정은 적용하지 않습니다.
- 선택한 프로필이 삭제되거나 사용할 수 없으면 기본 연결로 몰래 전환하지 않고 오류를 표시합니다.
- API 키는 스토리부스터가 별도로 저장하지 않습니다.

### 자동 진단 주기

- 기본값: 캐릭터 응답 `10회`
- `5~15회` 또는 `자동 진단 끄기`를 선택할 수 있습니다.
- 장르·캐릭터 부스터가 함께 켜져도 같은 시점에 한 번만 호출합니다.
- 주기는 전역 설정이며, 진행 횟수와 최근 진단 결과는 채팅별로 따로 저장됩니다.

### 플롯 생성 토큰

- 기본값: `1200`
- 첫 요청에는 사용자가 설정한 값을 그대로 적용합니다.
- 응답이 실제로 잘려 JSON이 끝나지 않은 경우에만 더 넉넉한 값으로 한 번 자동 재시도합니다.
- 응답이 계속 잘린다면 값을 높이거나 다른 연결 프로필을 사용해 보세요.
- 스토리부스터 자체의 최대 제한은 없으며 실제 한도는 연결 모델과 제공자 설정을 따릅니다.

### 출력 언어

- `한국어`
- `English`

플롯 후보, 장르 추천 이유와 캐릭터 기준 생성에 공통으로 적용됩니다. 실제 롤플 응답 언어와 내부 영문 주입 프롬프트는 바꾸지 않습니다.

## AI 호출과 토큰 사용

다음 기능은 버튼을 누르거나 설정한 진단 주기에 도달할 때 추가 AI 호출을 사용합니다.

- 플롯 자유 생성과 내 아이디어 작성
- 다듬기와 새 방향
- 현재 롤플 장르 추천
- 캐릭터 시트 요약·다시 요약
- 캐릭터 전용 상시 앵커 다시 생성
- 장르 또는 캐릭터 수동 진단
- 활성화된 자동 통합 진단

상시 장르·캐릭터 부스터와 `DRIFT GUARD`는 별도 분석 호출 없이 일반 캐릭터 응답에 지침을 함께 전달합니다. 상시 장르 프롬프트는 매 응답의 토큰 부담을 줄이기 위해 장르 정체성·표현·효과와 핵심 혼동 방지 규칙만 압축해 사용하고, 더 상세한 질감 기준은 추천·진단에서 함께 확인합니다. 장르와 캐릭터 부스터를 함께 켜도 같은 주기의 진단은 한 번만 호출됩니다.

토큰 비용을 줄이고 싶다면 자동 진단을 끄고 필요할 때만 수동 진단을 사용하거나, 저렴한 모델의 연결 프로필을 지정하세요.

## 분석에 사용하는 대화 범위

- 플롯 생성: 최근 펠소·캐릭터 메시지 합계 10개
- 장르 추천: 최근 펠소·캐릭터 메시지 합계 15개
- 자동 통합 진단과 탭별 수동 진단: 최근 캐릭터 응답 최대 10개와 가장 최근 교환을 이해하기 위한 최신 펠소 메시지 1개. 펠소 메시지는 반응 맥락으로만 사용하고 번호·평가는 캐릭터 응답에만 적용합니다.

비정상적으로 긴 단일 메시지는 앞뒤 맥락을 남긴 채 분석용 길이만 제한합니다. 따라서 일반적인 롤플 범위는 유지하면서 한 메시지가 입력 토큰을 과도하게 독점하는 일을 줄입니다.
- 캐릭터성·캐릭터 해석 진단: 위 범위와 7개 항목으로 저장된 짧은 캐릭터 기준

장르 진단에서 펠소 메시지는 관계와 장면 연속성을 이해하기 위한 맥락으로만 사용하며 평가는 캐릭터 응답만 대상으로 합니다. 전체 채팅을 매번 보내지 않고 현재 장면에 가까운 메시지만 사용해 토큰 사용과 오래된 맥락의 간섭을 줄입니다.

## 저장 방식

- 주·보조 장르, 자동 진단 진행 상태와 최근 진단 결과 1개: 채팅별 저장
- 캐릭터 기준 7개 항목, 항목별 핀 상태, 캐릭터 전용 상시 앵커와 갱신 상태: 캐릭터별 전역 저장
- 최근 플롯 추천 최대 5개: 채팅별 저장
- 사용자 장르와 사용자 플롯 카테고리: 확장 전체에서 공유
- 사용 기능, 자동 진단 주기, 출력 언어, 생성 토큰과 장르/캐릭터·플롯 연결 프로필: 전역 설정

같은 메시지의 리롤·스와이프는 자동 진단 횟수에 중복으로 포함하지 않습니다.

## 용어

- **캐릭터**: 펠소와 직접 롤플하는 메인 캐릭터, 내부 표기 `{{char}}`
- **펠소**: 사용자가 롤플에서 맡는 인물, 내부 표기 `{{user}}`
- **NPC**: 캐릭터와 펠소 외의 주변 인물

스토리부스터는 펠소의 행동, 대사와 감정을 AI가 서술해도 되는지 별도로 제한하지 않습니다. 해당 범위는 사용자의 프리셋, 캐릭터 카드, 작가 노트와 기존 대화 방식을 따릅니다.

## 모델 호환성

OpenAI 호환 응답 형식뿐 아니라 Gemini의 응답 구조와 Thinking 모델의 reasoning 출력을 읽을 수 있도록 보완되어 있습니다. Gemini 3.1 Pro에서도 장르 추천과 플롯 생성·다듬기·새 방향의 동작을 확인했습니다.

모델과 제공자마다 JSON 출력, 최대 토큰, 안전 설정과 프롬프트 준수 정도가 다르므로 모든 연결에서 완전히 같은 결과를 보장하지는 않습니다. `19금` 장르를 포함한 출력 수위도 사용 중인 모델, 제공자 정책과 프리셋의 영향을 받습니다.

## 문제 해결

### 스토리부스터가 보이지 않아요

- 확장 관리 화면에서 활성화되어 있는지 확인합니다.
- 설치 폴더 안에 `manifest.json`, `index.js`, `style.css`가 바로 들어 있는지 확인합니다.
- SillyTavern을 새로고침합니다.
- 계속 나타나지 않으면 브라우저 개발자 도구의 콘솔을 확인합니다.

### `MAX_TOKENS` 또는 JSON 오류가 떠요

- 플롯 생성 토큰을 높여 다시 시도합니다.
- Thinking이 적은 모델이나 다른 연결 프로필을 사용합니다.
- 연결 프로필이나 제공자 측 최대 출력 토큰이 너무 작게 설정되어 있지 않은지 확인합니다.

스토리부스터는 잘린 JSON을 감지하면 더 넉넉한 토큰으로 한 번 자동 재시도합니다.

### 설정한 언어와 다른 언어로 출력돼요

- 확장 관리 화면의 `출력 언어`를 확인합니다.
- 결과를 다시 생성합니다.
- 계속 발생하면 다른 모델이나 연결 프로필로 확인합니다.

### 자동 진단 호출을 사용하고 싶지 않아요

확장 관리 화면의 `자동 진단 주기`에서 `자동 진단 끄기 · 추가 호출 없음`을 선택하세요. 상시 부스팅과 수동 진단은 계속 사용할 수 있습니다.

## 버전

현재 배포 버전: **1.0.0**

1.0.0에서는 장르 부스터에서 캐릭터 관련 기능을 분리해 `캐릭터 부스터` 탭을 추가했습니다. 캐릭터 시트를 7개의 짧은 기준으로 나눠 저장하고, 같은 분석 호출에서 캐릭터 전용 영문 상시 앵커를 함께 만듭니다. 각 기준은 직접 편집·자동 저장·잠금·개별 재생성하거나 핀으로 보호한 채 나머지만 다시 요약할 수 있습니다. 전역 설정에서는 세 부스터를 각각 완전히 끄고 켤 수 있으며, 장르/캐릭터 분석과 플롯 생성에 서로 다른 연결 프로필을 지정할 수 있습니다. 자동 진단은 활성화된 장르와 캐릭터를 한 요청에서 함께 확인하고, 수동 진단은 누른 탭만 점검합니다. 다음 응답에는 최대 두 가지 보정만 적용하며 캐릭터 관련 보정에는 직접 연관된 저장 기준도 최대 2개만 일회성으로 사용합니다. 상시 캐릭터 프롬프트에는 전체 기준 대신 `{{char}}`용 짧은 전용 앵커와 공통 보강 규칙만 사용합니다. 사건은 자연스럽게 발생할 수 있지만 장르를 증명하기 위해 강제하지 않도록 정리했습니다. 기본 장르에는 서로 다른 혼동 방지 기준을 가진 `롬콤`, `앵스트`, `데드 도브`를 추가하고 기존 `19금` 표기는 명확한 `NSFW`로 바꿨습니다. 배포 전 안정화에서는 주 장르 혼동 방지 지침 누락, 채팅 이동 중 캐릭터 편집·분석 격리, 플롯 로그 경계와 한국어 출력 판정을 보완했으며, 진단은 캐릭터 응답 10개와 최신 펠소 맥락 1개만 사용하도록 입력 토큰 범위를 줄였습니다.

0.11.1에서는 일부 모델이 플롯 후보 대신 롤플 장면이나 캐릭터 응답을 생성할 수 있는 문제를 보완했습니다. 대화 로그를 분석 자료로 명확히 구분하고 로그 뒤에서 플롯 기획안 요청을 다시 강조합니다. 직접 대사·내면 독백·완성된 장면처럼 보이는 결과는 감지 후 한 번 자동으로 기획안 형태로 다시 정리하며, 보정에 실패한 장면형 결과는 추천 기록에 저장하거나 화면에 표시하지 않습니다.

0.11.0에서는 모든 기본 장르를 정체성·구체 신호·캐릭터/관계 효과·질감·혼동 방지 기준으로 다시 정리했습니다. 매턴 장르 앵커는 압축해 유지하고 상세 기준은 추천·진단에 활용합니다. 플롯 카테고리에는 현재 대화의 구체적 근거와 카테고리 고유 방향을 확인하는 자기점검을 추가했습니다. 생성·진단 도중 채팅이나 장르 설정이 바뀌어도 결과가 섞이지 않도록 작업 스냅샷을 고정했으며, 이전 SillyTavern 생성 경로에서도 지정한 최근 대화 범위를 명시적으로 전달합니다. 플롯 출력 토큰은 첫 요청에서 설정값을 그대로 사용하고 실제 잘림에만 한 번 확장합니다.

0.10.4에서는 보조 장르를 조건부 렌즈로 다시 정의해 `활성 / 대기 / 약화 / 미사용`으로 구분합니다. 근거가 없지만 적용할 자연스러운 기회도 없는 장면은 보정하지 않으며, 최근 진단 결과는 근거 번호 대신 일곱 개 핵심 상태를 간결한 카드로 표시합니다.

0.10.3에서는 수동·자동 장르 진단이 최근 캐릭터 응답 최대 8개를 검토하며, 펠소 메시지는 맥락으로만 사용합니다. 진단 AI가 주·보조 장르의 근거가 나타난 캐릭터 응답 번호를 제출하고, 확장이 근거 수를 다시 검증하여 장르 불일치의 과도한 안정 판정을 줄였습니다.

0.10.2에서는 진단 기반 1회용 보정을 더 명확하게 강화하고, 프롬프트 제목을 `GENRE ANCHOR`로 정리했습니다.

0.10.1에서는 장르 불일치 진단 기준을 강화하고, 백그라운드 진단 후 보정 취소 버튼이 비활성화될 수 있는 문제를 수정했습니다.

0.10.0에서는 최근 장르 진단 결과, 적용 전 보정 취소, 진단 맥락 개선, 장르·플롯 주입 깊이 분리와 연결 프로필 고정·검증을 추가했습니다.
