# 📖 스토리부스터 (StoryBooster)

SillyTavern 롤플레이의 **장르감·캐릭터성·다음 전개**를 보조하는 확장입니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 장르 부스터 | 주·보조 장르 선택, 장르 추천, 수동·자동 진단 |
| 캐릭터 부스터 | 캐릭터 기준 생성·갱신·편집, 저장 버전 비교와 항목 복사 |
| 플롯 부스터 | 사건·전개 아이디어 생성, 아이디어 보관함, 자동 랜덤박스 |

진단에서 확인된 문제는 다음 응답에 한 번 보강합니다. 각 부스터는 따로 켜거나 끌 수 있습니다.

## 설치·업데이트

1. 기존 확장과 설정을 백업합니다. 확장 폴더 백업은 SillyTavern이 확장을 읽는 위치 밖에 보관해 주세요.
2. ZIP을 푼 뒤 안쪽 `storybooster` 폴더의 **내용물**을 기존 스토리부스터 설치 폴더(현재 `manifest.json`이 있는 곳)에 덮어씁니다. 기존 폴더의 이름이 `storybooster`가 아니어도 그 폴더를 그대로 사용합니다. 처음 설치하는 경우에는 안쪽 `storybooster` 폴더를 제3자 확장 위치에 넣어 주세요.
3. SillyTavern을 재시작하고 브라우저를 새로고침한 뒤 **마법봉 메뉴 → 스토리부스터**에서 버전을 확인합니다.

같은 확장을 두 폴더에 넣으면 중복으로 로드될 수 있습니다.

## 빠른 사용법

- **장르**: 주 장르와 필요한 보조 장르를 선택합니다.
- **캐릭터**: 기준을 생성·검토하고 전용 앵커를 준비합니다.
- **플롯**: 카테고리나 내 아이디어로 다음 전개를 생성합니다.

같은 캐릭터 카드로 새 채팅을 만든 뒤 첫 메시지를 보내기 전에 스토리부스터를 열면 **이전 설정 가져오기 / 새로 시작**을 한 번 선택할 수 있습니다. 이전 설정은 주·보조 장르, 사용할 캐릭터 기준 버전, 비밀 모드, 자동 랜덤박스 허용 여부입니다. 진단 기록·보정·플롯 보관함은 이어받지 않으며, 가져오기 자체에 AI 비용은 없습니다. 기존 사용자는 업데이트 후 설정해 둔 채팅을 먼저 한 번 열어 주세요.

자동 랜덤박스는 플롯 탭에서 채팅별로 허용합니다. 전역 플롯 부스터와 자동 진단 주기도 켜져 있어야 합니다. 준비된 후보는 취소할 수 있습니다.

## Jev 연결 · 선택 사항

1. 전역 확장 설정의 **Jev 진단**에서 사용 안내에 동의합니다.
2. **Typesafe** 또는 **NanoGPT**를 선택하고 해당 제공자의 API 키를 입력합니다.
3. **키 저장 → 연결 테스트**를 진행합니다. 새로고침할 때마다 다시 테스트할 필요는 없습니다.

연결하면 기존 자동·수동 진단의 판정을 Jev로 진행합니다. 판단 이유와 보정문은 기존 진단 연결 모델이 작성합니다. Jev를 연결하지 않아도 기본 진단을 사용할 수 있습니다.

요청은 기존 SillyTavern 서버가 중계하며 추가 서버 플러그인은 필요하지 않습니다. 진단할 롤플 내용과 선택 기준이 제공자에 전송되고 API 비용이 발생합니다.

**API 키는 이 브라우저에 평문 저장됩니다.** 기존 암호화 키도 복호화 가능한 환경에서 평문 저장본으로 자동 이전됩니다. 다른 기기·브라우저·접속 주소를 쓰거나 브라우저 데이터를 삭제하면 다시 입력해야 합니다. 키는 확장 설정·채팅·진단 보고서에 포함하지 않습니다.

## 최근 업데이트 · v1.7.9

- 자동진단 취소 시 다음 새 AI 답변 1회 뒤에 재진단합니다. 대기 중 추가 번역·수정으로 실행 기회가 사라지지 않도록 보완했습니다.
- 진단 성공 전에는 주기를 다시 10회로 표시하지 않으며, 바쁜 시점에 놓친 진단도 다음 새 답변에서 실행합니다.
- 캐릭터 카드 변경 알림은 실제 수정의 최초 감지부터 3초 뒤 한 번만 표시합니다. 연속 수정으로 시간을 미루지 않고, 뒤늦게 발견한 변경은 창 안의 안내로 표시합니다.

- 캐릭터 앵커 입력과 영문 주입 한도를 각각 2,400자로 통일하고, 생성 결과가 한도를 넘으면 잘라 저장하지 않습니다.

## 이전 업데이트 · v1.7.8

- 창이 열리지 않거나 창을 열 때 진행 중인 진단·랜덤박스가 취소되는 문제 수정
- 같은 캐릭터의 새 채팅에 이전 장르·캐릭터·플롯 설정 가져오기 추가
- 장르 변경 시 캐릭터 보정 유지, 리롤·번역과 지연된 수신 알림 처리 개선
- 채팅 삭제 후 자동 랜덤박스 대기 횟수 개선
- 캐릭터 기준 백업을 나눠 복원할 때 부모 버전 연결 유지, 긴 이름 지원

내용 변경으로 재진단하면 추가 API 비용이 발생할 수 있습니다.
